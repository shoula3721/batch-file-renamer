批量文件改名 · 使用说明

版本 37.21.beta3 · 预览先行 · 先备份后改名 · 随时可还原

快速开始

  1. 点击“添加”选择文件，或把文件 / 文件夹拖进窗口（Ctrl+O 添加文件）。
  2. 在左侧“整体 / 替换 / 添加删除 / 元数据”标签页里设置规则。
  3. 查看“拍摄时间”“预览”列；确认无误后点击“开始重命名”。
  4. 执行前会先写入 JSON 备份，再通过临时名两阶段改名，失败自动回滚。
  5. 需要反悔时按 Ctrl+Z，或使用“编辑 → 一键还原”。

命名规则

符号含义示例
*当前文件名（不含扩展名），已应用添加删除与替换假期_* → 假期_IMG_001
#编号，按列表当前顺序生成照片_### → 照片_001
{date}日期，格式由元数据页设置2026-11-21
{time}时间 HHMMSS214000
{datetime}日期时间2026-11-21_214000
{name}原文件名（不含扩展名）IMG_001
{ext}扩展名JPG
{size}文件大小（字节，可写 {size:05d}）04823
{mtime} / {ctime}文件修改时间 / 创建时间2026-11-21_203102
{exif}拍摄时间原文2026:11:21 21:40:05
{title}标题 / 曲名Night Drive
{artist}艺术家 / 导演Aoi
{album}专辑 / 系列City Lights
{genre}风格 / 分类Synthwave
{tag_year}发布年份2019
{camera}相机型号X100V
{lens}镜头23mm F2
{iso}ISO 感光度160
{aperture}光圈（文件名安全写法）f2.8
{n}编号（同 #）1

规则里还可以给日期写自定义格式，例如 {date:%Y%m%d}；\*、\#、\{ 输出字面量。

替换与正则

  • 普通替换默认区分大小写，可关闭“区分大小写”或勾选“仅替换首次匹配”。
  • 勾选“使用正则表达式”后支持捕获组：^IMG_(\d+) → 照片_$1。
  • 也可以写 \1 或 ${name}；正则非法时输入框下方会变红提示，预览不会执行。
  • “包含扩展名”决定替换范围是否包括扩展名部分。

拍摄时间与元数据

  • 图片读取 EXIF DateTimeOriginal；MP4/MOV 读取 mvhd 创建时间（UTC）。
  • 找不到时自动回退文件修改时间，列表用灰色 ⓘ 标记；悬停可看来源与原文。
  • 日期来源、日期格式（含自定义 strftime）、时区都在“元数据”页设置。
  • 读取结果会缓存；文件被外部修改后自动失效。右键可选择“重新读取拍摄时间”。
  • 视图 → 按拍摄时间排序，或点击“拍摄时间”表头切换升 / 降序。

筛选、排序与编号

  • 上方筛选栏可选扩展名，或输入 mp4;mkv 多选；状态栏显示 筛选 12/55。
  • 有筛选时执行改名会二次确认，只处理筛选出的文件。
  • 编号 # 始终按列表当前顺序生成；排序或上移下移会改变编号。

备份、撤销与还原

  • 每次改名 / 还原都会先写 JSON 备份到 %APPDATA%\批量文件改名\backups，最多保留 100 个批次。
  • 所有改名先改成同目录临时名（.~br_*.tmp），再落到目标名，绝不覆盖已有文件。
  • Ctrl+Z、右键菜单或结果弹窗可以撤销最近一次重命名。
  • “文件 → 备份管理”或“编辑 → 一键还原”可查看全部批次并选择性还原； 原位置被占用时默认跳过，也可自动加 (1)，不提供覆盖。
  • 程序异常退出后重新打开，会提示恢复未完成的批次。

方案导入 / 导出

导出的 .bfr.json 包含全部规则、元数据设置、筛选扩展名与排序方式，不包含文件列表， 因此换一台电脑或换一个目录也能直接复用。窗口大小、标签页与最近方案会自动记住。

常见问题

为什么执行后“状态”显示未更改？
改名成功后列表会用新文件名重新预览；如果当前规则对新名字没有变化，就会显示“未更改”， “结果”列仍保留“成功”。

为什么预览列出现 (1)？
目标名称与目录里已有文件冲突，且开启了“自动解决命名冲突”。执行时也会避开同名文件。

文件被占用 / 只读怎么办？
程序会重试 3 次；仍失败则该文件标记失败并保留原文件，其余文件继续处理。结果弹窗可查看原因。

改名到一半强制结束进程会怎样？
重启程序会提示恢复未完成批次，按备份里的临时名或新名称还原。备份 JSON 请勿手动删除。

exe 首次运行提示 SmartScreen？
未签名程序的正常提示，确认来源后可选择“仍要运行”；正式分发建议代码签名。

备份目录：%APPDATA%\批量文件改名\backups。本帮助为离线内容，不访问网络。
